# Forest LiDAR Tree Annotation Sample Project

This Supervisely point cloud project contains one UAV LiDAR forest plot (FOR-instance, CULS plot 1, 1,816,672 points), converted to PCD and recentred to the origin, with the classes `tree` (Cuboid) and `tree_points` (Point Cloud) and no labels.

Source: FOR-instance (Puliti et al., 2023), https://doi.org/10.5281/zenodo.8287792. Data licensed under CC BY 4.0.
